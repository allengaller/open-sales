# open-sales

从零重学销售的个人修炼场：把自己当产品经营，把销售当系统运行。

## 内容

- [营销学院](营销学院/README.md) —— 本地营销学院：9 门课程 + 3 条学习路径（完整体系 / 求职速成 / 自由职业起航）+ 毕业标准，逐课训练通关。
- [营销方法论体系](营销方法论体系.md) —— 主文档（全景地图）：底层认知、技能盘点与组合优势、销售全流程、经典方法论（SPIN / Challenger / MEDDIC / Sandler）、沟通工具箱、度量复盘、90 天实战计划、模板库。

## 快速开始

1. 先读[《营销方法论体系》](营销方法论体系.md)建立全景（30 分钟）。
2. 进入[营销学院](营销学院/README.md)选一条学习路径，逐课完成"练习"产出物——只读不练等于没学。
3. 学完前八门课后进入[九十天训练营](营销学院/09-九十天训练营/README.md)，在真实市场里拿到第一个成交或 offer。
4. 话术库、案例拆解笔记等个人产出，建议在本仓库持续沉淀。
