# 课程 05：经典方法论——七大流派精读

> **前置课程**：课程 01（底层认知）/ 课程 04（销售全流程，先跑通流程再精读方法论）
> **预计学习时长**：6–8 小时（含练习）
> **课程性质**：理论深化课。方法论不是话术集，是**不同战场下的作战理论**——学完你该能判断"我这单该用哪套打法"。
> **主线案例**：陈默的单子会在不同流派下被反复使用，让你看到同一件事的七种解法。

## 课程目标

学完本课程，你应该能够：

1. 说出七大流派各自回答的核心问题、诞生背景与适用条件。
2. 用流派选择决策树，为自己的具体机会（求职/接单/大客户）选择主打法与辅助打法。
3. 把每个流派至少一个工具落地到自己的销售系统（话术库/清单/提问卡）。
4. 识别自己过去"混用流派"犯的错，并说出正确用法。

## 导论：为什么销售方法论有流派之分

销售方法论不是真理之争，而是**不同交易形态下的最优解**。决定用哪套打法的三个变量：

```
交易金额 × 决策周期 × 决策人数
```

- 小额、快周期、单人决策：重关系与效率（信任销售、简化版顾问式）。
- 中额、中周期、小团队决策：重深谈与价值（SPIN、顾问式、Gap Selling）。
- 大额、长周期、多角色决策：重过程管理与差异化（MEDDIC、Challenger）。

一张总览表（本课地图）：

| 流派 | 一句话 | 诞生背景 | 核心战场 |
|---|---|---|---|
| 顾问式 | 先诊断后开方 | 专业服务实践 | 一切复杂销售的母体 |
| SPIN | 用提问让客户自己说出痛 | Rackham 3.5 万访谈研究 | 深谈阶段的方法论 |
| Challenger | 用洞察 teaching 客户 | CEB 对 B2B 销售的研究 | 同质化红海的差异化 |
| Sandler | 双向资格筛选，不成在早 | Sandler 1970s 创立 | 防止无效跟进 |
| MEDDIC | 大单资格六要素 | Jack Napoli 在 AMD/PCS 实践 | B2B 大单过程管理 |
| Gap Selling | 卖现状与未来的差距 | Keenan 2018 | 价值量化与提案 |
| 关系/信任 | 信任即管道 | 老而常新 | 长周期、圈子市场 |

## 第 1 课 顾问式销售：一切复杂销售的母体

### 讲解

**起源**：从医生诊疗模式演化而来——没有人责怪医生"先检查再开方"，但人人警惕上来就推销的药贩子。顾问式销售把销售重构为"诊断 → 开方 → 治疗"。

**核心模型**：

```
诊断（现状与代价）→ 开方（方案与路径）→ 治疗（交付与陪跑）
```

三个纪律：①诊断不收费但诊断要**专业**（结构化提问，见 SPIN 课）；②没完成诊断不开方——"需求不清就报价"是顾问式的大忌；③医生可以转诊——敢于说"这个问题不归我管"（同时建立了课程 01 信任方程的分母优势）。

**收费诊断的正当性**：成熟顾问可以对诊断本身收费（"现状评估"），这是从"被挑选的乙方"变成"被预约的医生"的分水岭。个人售卖者起步期可免费，但流程必须同样专业。

### 应用示例（个人售卖）

陈默第一次见林芳，头 40 分钟只做诊断：画出现有对账流程图、量化每月耗时、列出历史事故。**诊断产出物本身就让林芳觉得"这 40 分钟已经值了"**——这是顾问式的复利：诊断即价值。

### 不适用与常见误用

- 不适用：标准化低价产品（客户不需要被诊断，只需要比价）。
- 误用 ①：把"多问两句"当诊断——没有结构化产出物（流程图/清单/数字）的提问只是聊天。
- 误用 ②：诊断完不敢报价，用"方案折扣"补偿心虚——诊断越专业，报价越该硬。

### 练习与自测

练习：给你的核心服务设计一张"诊断画布"（5–8 个必问项 + 产出物格式）。
自测：①"诊断即价值"怎么验证？②什么时候可以开始收诊断费？

## 第 2 课 SPIN Selling：深谈阶段的实证方法论

### 讲解

**起源**：Neil Rackham 带领 Huthwaite 研究团队分析了约 3.5 万个销售访谈，发现——大单销售中，"能说会道"与成交**负相关**，成交者赢在提问顺序。SPIN 是对访谈数据的归纳，不是理论推演。

**核心模型**：四类问题的心理学递进——

```
S 情境问题：了解背景（客户耐心最低，能调研就别问）
P 难点问题：让客户说出问题（痛苦浮出水面）
I 影响问题：放大问题的代价（分水岭：问透 I，需求自然生长）
N 收益问题：让客户自己描述解决后的价值（自证式说服）
```

**关键发现**：新手大量问 S（显得勤快但惹人烦）；普通销售停在 P（"我们有这问题"→ 然后拼价格）；**顶尖销售把 I 问到客户自己说出数字**（"这么一算一年 40 万人工"），N 只是收网。

完整对话示例见 [课程 04 第 3 课](../04-销售全流程/README.md)（30+ 轮标注版），此处不重复。

### 应用示例（个人售卖）

同一句 P 回答后的三种走法对比：

> 客户："对账是挺慢的。"
> ❌ 新手走法："我们的自动化工具可以帮您提速！"（跳到方案，P 后直接推销）
> ⚠️ 普通走法："一般要多久？"（又回 S，原地打转）
> ✅ SPIN 走法："这个慢，每个月会连累到谁？"（I 问题：影响链展开）

### 不适用与常见误用

- 不适用：客户已经痛到不需要被引导（明天就截止的紧急采购），此时 SPIN 是折磨——直接给方案。
- 误用 ①：机械地问完 27 个问题像审讯——SPIN 是地图不是问卷，一个 I 问题问透胜过十个 P。
- 误用 ②：跳过 I 直接 N（"如果解决了是不是很棒？"）——没有代价支撑的美好是空谈。

### 练习与自测

练习：把课程 04 第 3 课的对话换一个行业重写一遍（保留层级标注）。
自测：①为什么说 I 问题是分水岭？②S 问题的正确处理方式是什么？

## 第 3 课 Challenger：用洞察重塑客户的认知

### 讲解

**起源**：Matthew Dixon 与 Brent Adamson（CEB，后并入 Gartner）基于对数千名 B2B 销售的研究提出：复杂销售中表现最好的不是"关系构建者"，而是 **Challenger（挑战者）**——敢于教客户新东西、敢于施加压力的类型。

**核心模型 Te-Ta-TC**：

1. **Teach（教学）**：带给客户一个关于他自己业务的**反直觉洞察**（"您以为成本在 X，其实大头在 Y"）。
2. **Tailor（定制）**：把洞察按角色裁剪（对 CFO 讲风险、对经理讲效率）。
3. **Take Control（掌控）**：温和地推进进程——敢要承诺、敢挑战预算流程，但保持建设性。

**商业洞察的构造公式**：

```
洞察 = 客户的默认认知（"大家以为……"）
     + 被忽视的事实（"但数据显示/我们看到……"）
     + 重新定义的赢面（"所以真正该做的是……"）
```

### 应用示例（个人售卖）

陈默对 CFO 的 Challenger 时刻：

> "多数公司觉得对账慢是**人手问题**，所以第一反应是招人。但我们看过十几家跨境电商的账，慢的根源是**口径不统一**——加人只是加更多双手去做同一件错的事。先把口径标准化，再自动化，同样的人数产能翻三倍；反过来做，明年这个时候您还在招人。"

这一段让 CFO 沉默了十秒——**那一刻陈默不再是"外包供应商"，而是"见过世面的专家"**。

### 不适用与常见误用

- 不适用：你对该行业的理解没有超出客户时（没有真洞察硬教学，是灾难）；以及对方是专家型买家、比你懂。
- 误用 ①：把"掌控"演成傲慢——Challenger 的压力永远指向客户的成功，不是自己的成交。
- 误用 ②：洞察是观点没有证据——每个"其实"后面必须有案例或数据托底。

### 练习与自测

练习：用洞察构造公式给你的领域写 3 个教学点（每个 ≤60 秒口述）。
自测：①关系构建者为什么在复杂销售里输给挑战者？②Teach 与"忽悠"的分界线在哪？

## 第 4 课 Sandler：双向资格筛选与"不成在早"

### 讲解

**起源**：David Sandler 于 1967 年前后创立，核心洞见：**传统销售是单向推销，Sandler 把它改造成双向互相资格确认**——你在筛客户，客户也在筛你。

**三大支柱**：

1. **痛苦理论**：没有痛就没有单。Sandler 要求把痛挖到客户**亲口承认**并愿意为解决它做事，才继续投入。
2. **升级原则（Up-Front Contract）**：每次沟通前双方明确——今天谈什么、谈多久、可能的结果是什么、下一步是什么。消灭"聊得很好然后没有下文"。
3. **不成在早（Fail Fast/No 是好答案）**：资格不符尽早散伙，"可能的 no"比"拖延的 maybe"值钱——个人售卖者的时间是唯一不可再生资源。

**升级原则话术示例**：

> "今天 30 分钟，我想了解三件事：…… 如果聊完你觉得值得继续，我们约下一步深谈；如果觉得不合适，直接告诉我没关系——你最不想听的是我追着你问'考虑得怎么样'，我也不想追。"

### 应用示例（个人售卖）

陈默用 Sandler 淘汰了一个"僵尸机会"：某公司联系人热情但连续三次说"再等等"。第四次触达前，陈默发去升级式提问："帮忙确认一下：这个项目今年还在计划里吗？如果暂时不做，我先把名额放给别人，明年再聊？"对方坦承预算冻结——**一段 30 秒的对话，省下了两个月的无效跟进**。

### 不适用与常见误用

- 不适用：强买方市场（大厂招标），你没有筛选地位时慎用"散伙式"话术。
- 误用 ①：把资格筛选演成傲慢的"爱买不买"——Sandler 的筛选用**提问**完成，不用姿态。
- 误用 ②：对每个小单都全套流程——小额快单用轻量版（一句升级确认即可）。

### 练习与自测

练习：给你当前跟进中的每个机会做 Sandler 体检（痛被亲口承认了吗/有下一步契约吗/拖了多久了），连续超两周无契约的，今天发出"不成在早"式确认。
自测：①升级原则解决的是什么问题？②"可能的 no"为什么比"拖延的 maybe"值钱？

## 第 5 课 MEDDIC：大单的过程管理仪表盘

### 讲解

**起源**：Jack Napoli 在 PSS/AMD 时期总结的大单资格清单，后成为 B2B 企业销售的标准配置。MEDDIC 不教你怎么谈，它回答一个更冷的问题：**这个单子是真的吗？**

**六要素逐项详解**（每项配自检话术）：

| 要素 | 问题 | 自检话术（问自己/问客户） |
|---|---|---|
| **M**etrics 量化指标 | 客户的收益可量化吗？ | "做完这件事，哪个数字会变好？现在是多少，目标是多少？" |
| **E**conomic Buyer 经济决策人 | 谁最终签字？见过面吗？ | "预算最终谁批？我能不能和他 15 分钟对齐一下口径？" |
| **D**ecision Criteria 决策标准 | 他们按什么比选？ | "除了价格，你们最看重什么？以前选砸过吗？" |
| **D**ecision Process 决策流程 | 走哪些环节、谁参与、多长？ | "从今天到签约，中间还有哪几步？" |
| **I**dentify Pain 明确痛点 | 没有痛，就没有单。 | "这事不做，明年会怎样？"（答不上来 = 假单） |
| **C**hampion 内线冠军 | 谁在内部替你推动？ | "谁会在你不场时替这个项目说话？" |

**为什么"没有 Champion 的单是假单"**：大单的决策会议你进不去，你的故事必须有人替你讲。Champion 的识别标准：①主动给你内部信息；②愿意为推动项目花自己的政治资本；③你给他的人物任务（引荐/对齐口径）他都真做了。**培养动作**：给 Champion 弹药——一页纸的内部汇报材料、ROI 算法、常见质疑的应答（让替你说话的人有词可说）。

### 应用示例（个人售卖）

陈默对硬壳科技单的 MEDDIC 体检：M＝每月省 2 万人时 + 消除审计风险 ✅；E＝CFO 尚未见面 ⚠️（下一步：请林芳安排 15 分钟对齐）；D＝"数据不出内网、代码可维护" ✅（已给 IT 主管安全说明）；D2＝财务流程需 CFO + CEO 双批 ⚠️；I＝换汇损失事件 ✅；C＝林芳 ✅（已主动替他约 CFO）。**体检暴露两个 ⚠️，下一步动作自动浮现**——这就是 MEDDIC 的价值：不让你凭感觉乐观。

### 不适用与常见误用

- 不适用：小额快单（杀鸡用牛刀）；纯关系型圈子市场。
- 误用 ①：把 MEDDIC 当一次性表格——它是每周刷新的仪表盘，要素会退化（Champion 离职、预算挪用）。
- 误用 ②：只填表不行动——每个 ⚠️ 都必须翻译成本周动作，否则体检无意义。

### 练习与自测

练习：给你最重要的机会做一次 MEDDIC 体检表（六要素 + 状态 + 下一步动作），把所有 ⚠️ 排进本周日程。
自测：①为什么说 MEDDIC 管"是不是真单"，SPIN 管"怎么谈"？②Champion 的三条识别标准是什么？

## 第 6 课 Gap Selling：把差距卖出来

### 讲解

**起源**：Keenan（2018 年出版《Gap Selling: Getting the Customer to Buy》）提出的最现代的销售观之一：**客户买的不是产品，是从"现状"到"未来状态"的迁移**。销售的全部工作 = 丈量差距 + 让客户受不了这个差距。

**核心模型**：

```
痛点 = 现状 × (1 − 满意度)
差距 = 未来状态 − 现状
成交意愿 ∝ 差距被感知的大小
```

**九宫格提问矩阵**（Gap Selling 的实操工具，深谈时的结构化地图）：

|  | 现状 | 未来状态 | 差距 |
|---|---|---|---|
| **技术面**（流程/工具） | 现在怎么做的？ | 理想状态长什么样？ | 中间隔着什么？ |
| **量化面**（数字） | 每月耗多少人时/成本？ | 目标数字是多少？ | 差多少？值多少？ |
| **情绪面**（感受） | 现在什么感受？ | 解决后什么感受？ | 这份难受持续多久了？ |

### 应用示例（个人售卖）

陈默用九宫格填完林芳的单子：现状 = 6 店铺手工对账 3 天/月，情绪 = "5 号前睡不踏实"；未来 = 1 天出表 + 异常自动预警，情绪 = "审计季从容"；差距 = 每月 2 天 × 团队时薪 + 一次两万的汇率损失 + 睡不着觉。**他的提案标题直接写着："从每月 3 天到 1 天：硬壳科技对账现状与未来状态"**——卖差距，不卖脚本。

### 不适用与常见误用

- 不适用：冲动型/即兴型小额消费（没有可丈量的差距）。
- 误用：只丈量技术面差距（回到比价）；三个面里**量化面和情绪面才是报价的发动机**。

### 练习与自测

练习：用九宫格填你最重要的机会（九格填满，情绪面用客户的原话）。
自测：①为什么"现状"要写在提案第一页？②公式"痛点 = 现状 × (1−满意度)"对"满意度极高但没有未来"的客户意味着什么？

## 第 7 课 关系/信任销售：长周期市场的复利玩法

### 讲解

**起源**：最古老也最新的流派。在一个圈子里（行业、城市、校友、开源社区），**你的名声就是你的管道**——信任销售的资产是"被想到"（top of mind）：机会出现时，第一个被想起的名字拿走单子。

**核心工具：信任方程的运营化**（方程见 [课程 01](../01-底层认知/README.md)）：

| 变量 | 圈子里的积累动作 | 反面 |
|---|---|---|
| 专业能力 | 公开作品、行业分享、可复用的方法论 | 头衔堆砌 |
| 可靠度 | 小承诺必兑现（说发的资料一定发、说引荐一定引荐） | 随口答应然后消失 |
| 亲密度 | 记住同行的处境，一对一深聊 | 只在要单子时出现 |
| 自我导向 ↓ | 先给三次，再取一次 | 每次出现都带着索取 |

**弱关系理论的应用**（Granovetter，1973：新机会更多来自"泛熟人"而非密友）：圈子里最值钱的动作是**定期、带价值地激活弱关系**——不是群发问候，而是"看到 X，想到你在做 Y，或许有用"（操作节奏见 [课程 07 个人品牌课](../07-个人售卖实战/README.md)）。

### 应用示例（个人售卖）

陈默所在的跨境电商财务社群：他每月做一次免费的"对账口径门诊"（30 分钟帮一家公司看流程），三个月后社群里形成默契——"对账的事问陈默"。第四个月，两单 inbound 找上门，**他没做任何冷触达**。

### 不适用与常见误用

- 不适用：没有圈子属性的一次性交易市场（比价型电商平台）。
- 误用 ①：把"混脸熟"当信任销售——没有专业输出和可靠度的脸熟只是噪音。
- 误用 ②：只投入不收割，或只收割不投入——给取比 3:1 是可持续线。

### 练习与自测

练习：列出你所在最重要的 3 个圈子，给每个圈子写一个"每月一次的给予动作"。
自测：①"被想到"为什么比"被喜欢"值钱？②给取比失衡的两个方向各有什么症状？

## 第 8 课 流派组合：选择决策树与个人售卖者的推荐配方

### 讲解

流派之间不是互斥，是**分层组合**：一个完整单子里，不同阶段用不同流派。

**选择决策树**：

```
你的交易是什么形态？
├── 小额快单（<2 万，2 周内，1 人拍板）
│     → 轻顾问式（一次诊断）+ 信任销售（转介绍驱动）
├── 中额中周期（2–20 万，1–3 个月，小团队决策）
│     → 顾问式做框架 + SPIN 做深谈 + Gap Selling 做提案
│     + Sandler 轻量版做资格（升级原则防拖单）
└── 大额长周期（>20 万，3 个月+，多角色决策）
      → MEDDIC 做仪表盘 + Challenger 做差异化
      + SPIN 做每一层角色的深谈 + 信任销售做长期经营
```

**个人售卖者的推荐配方**：

| 你的处境 | 主打法 | 辅助 | 理由 |
|---|---|---|---|
| 刚起步无案例 | 顾问式 + SPIN | Sandler（防僵尸单） | 诊断能力是零成本的专业证明 |
| 求职 | SPIN + Gap Selling | Challenger（面试教学点） | 面试就是一场深谈+提案 |
| 自由职业接单 | 顾问式 + Sandler | MEDDIC 轻量版 | 时间是唯一产能，筛客户最重要 |
| 高客单咨询 | MEDDIC + Challenger | 信任销售 | 假单是大敌，差异化是溢价来源 |
| 圈子型市场 | 信任销售 | SPIN | 名声即管道 |

**新手最常见的流派混用错误**：

1. 小单用 MEDDIC 全家桶（客户被流程吓跑）。
2. 大单只用关系（"关系好"≠"是单子"，缺 MEDDIC 体检的乐观是幻觉）。
3. 深谈没做完就上 Challenger（没有诊断基础的"教学"是冒犯）。
4. 用 Sandler 的姿态对待把关人（筛选是筛决策链，不是筛每个角色）。

### 练习

1. 用决策树判定你当前所有在跟机会的形态与主打法，写进你的机会清单。
2. 检查上一条死掉的单子：死因是否与"流派错配"有关（如大单没做 MEDDIC）？
3. 从本课挑**一个**工具本周落地：诊断画布 / 九宫格 / MEDDIC 体检表 / 升级原则话术（贪多必失）。

### 自测

1. 为什么"一个单子全程只用一个流派"是错的？
2. 你的主力机会该用哪套配方？判断依据是哪三个变量？
3. Sandler 和 MEDDIC 都做资格筛选，它们的分工差别是什么？

## 过关标准

- [ ] 能不看资料画出总览表（七流派 × 一句话 × 适用战场）。
- [ ] 完成一次真实机会的 MEDDIC 体检（六要素 + ⚠️ 行动项）。
- [ ] 完成一次真实机会的 Gap Selling 九宫格（九格填满，含客户原话）。
- [ ] 写出 3 个你领域的 Challenger 教学点（每个 ≤60 秒，有证据托底）。
- [ ] 用决策树给自己所有在跟机会配好打法，并识别出至少一个过去的流派错配。

## 常见错误

1. **把方法论当话术集背**——方法论是战场判断力，先学"何时用"再学"怎么说"。
2. **追新弃旧**：Keenan 再新，也盖不住 Rackham 的实证底座；每个流派解决的问题不同。
3. **全盘套用**：个人售卖要的是"轻量版 + 组合"，原教旨主义全家桶只适合大厂大单。
4. **学完不动**：本课每个流派都留了一个可落地工具，一个都没用 = 没学。
