# 课程 07：个人售卖实战——三大场景与个人品牌

> **前置课程**：课程 02（PVP）/ 课程 04（全流程）/ 课程 06（沟通工具箱）
> **预计学习时长**：8–10 小时（含材料制作）
> **课程性质**：场景落地课。把前面所有武器装配进三个具体战场：**求职、自由职业接单、公司内部推动**，外加驱动一切的长期引擎——个人品牌。
> **主线案例**：陈默的三种身份切换（求职者 / 独立顾问 / 公司内推动者）。

## 课程目标

学完本课程，你应该能够：

1. 把简历从"职责清单"改写成"销售文案"（逐条 FABG 化 + 量化），并备好 10 个高频面试问题的故事映射。
2. 设计自己的定价结构（四模式）与迁移路径，写出一份含三档报价的完整提案。
3. 把一个想法翻译成老板的 KPI 语言，并设计一个"安全的 yes"式 pilot。
4. 搭起个人品牌内容飞轮：平台选择、选题库、内容日历、弱关系激活节奏。

## 第 1 课 求职：把自己卖给一个组织

### 讲解

求职就是一次完整销售战役，只是换了名字：

| 销售概念 | 求职场景 |
|---|---|
| ICP + 名单 | 目标公司清单（不是海投） |
| 触达 | 简历投递 / 内推 / 主动联系用人经理 |
| 深谈（SPIN） | 面试前半场：问团队的问题与痛 |
| 方案呈现 | 面试后半场：你的组合优势对准他的痛 |
| 异议与谈判 | 压力面 / 谈薪 |
| Champion | 内推人 / 友善面试官 |

**简历 = 销售文案**：HR 平均只扫一份简历十几秒——它不是档案，是广告。广告的主语必须是**结果**，不是职责。

### 简历改写：前后对照（FABG 化）

> ❌ 职责式（原文）：
> "负责公司财务系统的日常维护和报表开发，配合月度结账，使用 Python 和 SQL。"

> ✅ FABG 式（改写）：
> "把月度结账报表从手工 Excel 流程重建为 Python+SQL 自动化管线，**结账周期从 5 天压缩到 1.5 天**， freeing 财务团队每月约 60 人时；管线运行 18 个月零差错，被总部采纳为 3 家分公司的标准做法。"

改写公式：**动词开头 + 做了什么方法 + 数字结果 + 波及范围**。四要素缺一时按此顺序补：先补结果数字，再补范围。

没有数字的经历怎么办：补**比例/频率/规模**（"约 60 人时""3 家分公司""18 个月零差错"）——总有可量化的维度；实在没有，写相对变化（"从 X 降到 Y""提速约一半"）。

### 面试问答准备矩阵（10 问 × 故事映射）

| 高频问题 | 映射故事（课程 06 第 3 课的库） | 映射武器 |
|---|---|---|
| 介绍一下你自己 | 30 秒电梯陈述（课程 02） | PVP |
| 你最大的优势是什么 | 组合优势 + 数字案例 | Skill Stack |
| 讲一个你主导的项目 | 从零到一故事 | SCQA |
| 讲一次失败 | 失败复盘故事 | SCQA + 信任方程 |
| 你怎么处理 XX 难题（技术） | 救火故事 | SCQA |
| 为什么是我们公司 | 前置调研 + ICP 反向陈述 | 课程 03 |
| 你有什么要问我们的 | SPIN 问团队（见下） | 提问技术 |
| 你的缺点是什么 | 真实缺点 + 已建立的纠错机制 | 信任 |
| 为什么离开上家 | 中性事实 + 朝向性理由（不说旧主坏话） | — |
| 期望薪资 | 报区间不报现薪（见下） | 谈判 |

**"你有什么要问我们的"是全场最好的销售机会**，备三问：

```
1.（S/P）这个岗位未来三个月最需要解决的一件事是什么？
2.（I）这件事现在没解决，团队和您本人的压力是什么？
3.（N）如果半年后回头看，什么样算做成了？
```

问完这三问，你的自我介绍就有了对准的靶子——**面试后半场用他的答案定制你的呈现**。

### 谈薪剧本（要点版）

完整对话示例见 [课程 06 第 5 课](../06-沟通工具箱/README.md)。求职场景的六条纪律：

1. **绝不先报"当前薪资"**：被问先答"我更关注这个职位的匹配和区间，我的期望区间是 X–Y"。迫不得已时，报总包而非 base。
2. **锚定区间**：X = 你的真实目标，Y = 目标 +15–20%；区间下限就是你愿意接受的数。
3. **谈前必做市场分位**：同岗位招聘数据（平台薪资爆料）+ 问 2–3 个同行/猎头，定位 P50/P75。
4. **BATNA 管理**：手里有其他流程在走，谈判力自动抬升；没有时，"继续在现岗位"也是 BATNA，别自贬成零。
5. **总包思维**：base/签字费/年度奖/期权/远程/职级，六个维度里总有对方灵活的组合。
6. **拿到 offer 再谈**：口头意向 ≠ offer；书面 offer 前的砍价都是空转，书面后的 24–72 小时才是黄金谈判窗。

### 练习

1. 把简历每条经历 FABG 化改写（无数字的先补数字再改写）。
2. 填满 10 问映射矩阵——每个问题对应的武器/故事先写关键词，再口述成稿。
3. 用三问模板改造你的面试反问清单；下一次任何面试（哪怕是内部转岗）实战使用。

### 自测

1. 简历是档案还是广告？这个定位改变了哪三个写作决策？
2. 为什么"你有什么要问我们的"是销售机会而不是礼貌环节？
3. 为什么口头意向阶段砍价是空转？

## 第 2 课 自由职业/咨询：把自己按项目卖

### 讲解

**定价四模式**（个人生意的进化路线）：

| 模式 | 算法 | 适用期 | 上限 | 死穴 |
|---|---|---|---|---|
| 时薪 | 市场时薪 ×（1.2–1.5） | 起步、范围无法界定时 | 低（收入 ∝ 时间） | 惩罚效率——你越快越亏 |
| 按项目 | 拆解工时 × 折算费率 + 风险金 | 有 2–3 个案例后（主流） | 中 | 范围蔓延（scope creep） |
| 按价值 | 报价锚定客户收益的 10–30% | 有强信任 + 收益可量化 | 高 | 收益算不出来就报不出 |
| Retainer 月费 | 固定服务包 × 月 | 有持续需求的老客户 | 稳定 + 可预期 | 服务边界要清晰 |

**迁移路径**：时薪（前 3–5 单）→ 项目制（站稳）→ 项目 + 价值成分（溢价）→ Retainer（护城河）。**每一次迁移都在卖"结果"而不是"时间"**——这是课程 03 JTBD 的直接应用：功能任务卖给项目制，情感+社会任务才卖得出价值定价。

**不报价先深谈**：需求没量化（钱/时间/风险三项至少一项）之前不报价——报了也是猜，猜低了亏自己，猜高了吓跑人。深谈技术用 [课程 04 第 3 课](../04-销售全流程/README.md)。

**接单前资格筛选清单**（Sandler 轻量版，不满足 ≥4 条慎接）：

- [ ] 说出了一年内可量化的痛（钱/时间/风险）
- [ ] 经济决策人见过或可安排见到
- [ ] 有同类付费先例（招过人/买过服务）
- [ ] 预算范围已口头确认
- [ ] 有内部 Champion（使用者愿意配合）
- [ ] 时间窗合理（不是"上周就该做完"的恐慌单）

### 完整提案示例（陈默 → 硬壳科技，节选）

```
《从每月 3 天到 1 天：硬壳科技对账现状与未来状态》

一、我们的理解（现状 + 代价）
  6 店铺后台口径不一，合并对账 3 天/月；上月延迟致换汇计划推迟，
  汇率损失约 2 万；审计季需人工二次核对，财务经理 5 号前持续性加班。

二、目标状态
  月度合并对账 ≤1 天；口径差异自动标记；异常主动预警；
  管理层可实时查看统一口径看板。

三、路径（4 周三阶段）
  W1 口径标准化（交付：口径字典 1 份）
  W2 自动化管线（交付：脚本 + 文档，数据不出内网）
  W3 看板与预警（交付：管理层看板 + 预警规则）
  W4 陪跑交接（交付：SOP + 团队培训 1 场）
  双方投入：贵方财务接口人每周 3 小时

四、投资与选项
  基础版 3.5 万：管线 + 文档（解决功能）
  推荐版 5.5 万：+ 口径字典 + 看板 + 预警 + 1 个月陪跑（推荐）
  尊享版 7.5 万：+ 审计季全程陪跑 + 季度复盘 + 优先响应

五、为什么是我
  同规模跨境电商案例：结账 5 天 → 1.5 天，18 个月零差错（可提供联系人核验）

六、风险与保障
  分两期付款（启动 50% / 验收 50%）；W1 结束若口径梳理无进展，可终止并
  仅结 W1 费用；代码交付带文档，IT 可维护。

七、下一步
  本周内确认档位 → 下周一 W1 启动会（30 分钟）。
```

**三档报价的设计逻辑**：中档是你真想卖的（用高档抬它、用低档护它）；低档必须"不完整"（砍掉看板与陪跑，客户自己会算失去什么）；高档必须真实可交付。

### 范围蔓延（scope creep）应对话术

> 客户："顺手把采购那块也对一下呗，反正都是表。"
> ❌ "行吧……"（免费加量，项目利润归零）
> ✅ "可以纳入——它和销售口径是两套逻辑，我评估约 1.5 天工作量。两个选择：并入本期，推荐版上浮 8 千；或我先记入需求池，本期验收后按小项目单独做。你倾向哪个？"

公式：**接住需求 → 报出代价 → 给出选项**。每次免费答应越界，都是在教客户你的边界不存在。

### 练习

1. 写出你当前的定价卡（四模式各一个数字 + 你的迁移计划时间点）。
2. 用骨架写一份完整提案（真实机会；没有就虚构一个最可能的目标客户）。
3. 把资格清单跑在你最近拒绝/接受的一个机会上，回看决策对错。

### 自测

1. 为什么时薪模式"惩罚效率"？
2. 价值定价的前置条件是什么？哪个课程提供了它？
3. 三档报价中，低档为什么必须"不完整"？

## 第 3 课 内部推动：把想法卖给老板

### 讲解

公司内部卖想法（重构、采购工具、立新项目）与对外销售唯一的区别：**你卖的对象每天都会再见到你**——信誉的清算周期更短，过度包装的代价比外面更大。

**核心技术：KPI 语言翻译**。老板不关心技术先进性，关心他的考核表。翻译模板：

```
你的语言 → 老板的语言
"这个模块技术债严重" → "每加一个需求，开发时间多 20%，下季度排期已经排不下了"
"我想引入自动化测试" → "线上事故少一半，你们每月的事故汇报能少两页"
"这个工具能提效" → "两个人干三个人的活，编制不用加"
```

**ROI 一页纸结构**（内部提案的黄金格式）：

```
1. 现状与代价（用部门的数字：工时/事故数/延迟率）
2. 方案与投入（要的人/钱/时间，往少了说——但要真）
3. 收益（对齐老板 KPI 的 2–3 条，可验证）
4. 风险与退路（最坏情况损失多少，怎么退出）
5. 最小启动（本周就能做的第一步，花费 ≤ 一个下午）
```

**Pilot 设计三原则**：小成本（失败不心疼）、可见结果（两周内能拿出数字）、可退出（明确说"试点不成我们就停"）。**给决策者一个"安全的 yes"**：批一个下午的人，不需要勇气；批一个百万项目，需要。

**向上沟通的节奏管理**：老板最恨的不是坏消息，是**惊吓**。周报里持续预告（"预计月底出试点数据"），数据出来当天给结论——让他始终比你老板的老板慢半拍知道坏消息，而不是快半拍。

### 案例

陈默还在公司时想推动"数据字典制度"：没写技术方案，先花一下午做了件事——统计三个月内因"口径不一致"引发的返工（11 次、约 90 人时），做成一页纸给总监，申请"两周试点：只梳理营收一个域的口径"。试点结果：报表争议从每周 2 次降到 0。第二个月，制度被总监主动推到全部门——**陈默没卖"制度"，卖的是"总监在月会上少吵两次架"**。

### 练习

1. 把你最近想推动的一件事翻译成 KPI 语言（写出对应老板的哪条考核）。
2. 按 ROI 一页纸结构写出提案，pilot 缩到"一个下午可启动"。
3. 找一个同事预演答辩：让他只扮演"最挑剔的财务"，你只许用他的语言回答。

### 自测

1. 为什么内部销售的包装代价比外部更高？
2. Pilot 三原则各自解决决策者的什么恐惧？
3. "安全的 yes"在话术上长什么样？

## 第 4 课 个人品牌：内容飞轮与弱关系运营

### 讲解

前三个场景都是"推"，个人品牌是唯一的"拉"引擎：

```
作品/项目 → 沉淀为内容 → 吸引受众 → 带来机会 → 更好的作品/项目 →（循环加速）
```

**平台选择矩阵**（只选一个主平台深耕，其余分发——见课程 03 渠道课"重复出现"原则）：

| 平台类型 | 适合的人 | 你的 ICP 在吗 |
|---|---|---|
| 职业社交（LinkedIn/脉脉） | B2B 服务、求职导向 | 企业决策者密度最高 |
| 技术社区（GitHub/掘林等） | 技术型售卖者 | 影响者与同行 |
| 图文社区（公众号/小红书/知乎） | 咨询、知识服务 | 按垂直话题聚 |
| 视频平台（B站/抖音） | 表达欲强、能坚持出镜 | 泛人群 + 算法杠杆 |

选择标准只有一条：**你的 ICP（课程 03）日常出没在哪，就选哪**——不是"哪个平台火"。

**内容配方 60/30/10**：

- **60% 干货**（证明专业）：方法论、教程、拆解。选题公式 = `你的技能组合 × ICP 的痛点`（如"财务人看得懂的五分钟自动化"）。
- **30% 过程与复盘**（建立真实与信任）：项目手记、踩坑记录、失败分析。**这类内容的转化率常高于干货**——人跟人走，不跟教科书走。
- **10% 观点**（制造记忆点）：有立场的判断。"我反对 XX 的三个理由"——观点带来讨论，讨论带来算法分发。

**选题库起步（每类 10 个的方法）**：把课程 02 的资产清单 × 课程 03 的痛点清单做交叉表，每个格子问"我能教/能拆/能吐槽什么"——30+ 选题一次产出。

**内容日历（周模板）**：

```
周一 30 分钟：定本周选题（从选题库取）
周三 60 分钟：初稿（一次写完，不修改）
周四 30 分钟：修改 + 配图 + 发布
周五 15 分钟：回复全部评论（社区即渠道）
每天 10 分钟：互动 3 条目标客户的动态（真实的，非套路）
```

频率底线：**每周一篇，坚持 12 周**。个人品牌的门槛不在才华，在连续性——大多数竞争者在第 6 周消失。

**弱关系激活的 12 个月节奏**（Granovetter 弱关系理论，见 [课程 05 信任销售课](../05-经典方法论/README.md)）：

```
每月 5 次"带价值出现"：给一位久未联系的泛熟人发——
  一条和他业务相关的具体信息/文章 + 一句"想到你"
  （禁止：群发、节日模板、开口要事）
每季度 1 次"轻聚会"：约 2–3 位泛熟人小聚/咖啡
每年 2 次"给予盘点"：我这一年帮过谁、引荐过谁、推过谁——
  给予账户只存不取，机会来时自然轮到你
```

**飞轮冷启动顺序**（前 3 个月别指望 inbound）：第 1 月出 4 篇干货（建立"值得看"的基线）→ 第 2 月把每篇发给 3–5 位相关的弱关系（种子流量 + 反馈）→ 第 3 月开始在目标社群做一次分享（把内容变成露面）。inbound 线索通常在第 4–6 个月出现——**坚持不到那时候的人，永远验证不了飞轮**。

### 练习

1. 用平台矩阵选定主平台，写一句"为什么我的 ICP 在这"。
2. 产出你的 30 个选题（资产 × 痛点交叉法），排出前 4 周日历。
3. 今天发出前 3 条"带价值出现"的弱关系消息。

### 自测

1. 为什么过程类内容转化率常高于干货类？
2. 飞轮的冷启动顺序为什么必须"内容在前、分发在后"？
3. 弱关系激活为什么禁止"开口要事"？

## 过关标准

- [ ] 简历全部经历 FABG 化，10 问映射矩阵填满，三问反问实战用过一次。
- [ ] 定价卡成文 + 一份完整三档提案（真实或高保真虚构）。
- [ ] 一个内部想法完成 KPI 翻译 + ROI 一页纸 + 一个下午版 pilot 方案。
- [ ] 主平台选定、30 选题入库、前 4 周内容日历排好、3 条弱关系激活已发出。

## 常见错误

1. **海投思维**：把求职当抽奖，而不是"名单 → 触达 → 深谈"的销售战役。
2. **时薪躺平**：效率越高越忙越穷——不迁移定价模式，收入永远钉在时间上。
3. **内部推销用技术语言**：卖出去的从来不是方案本身，是老板 KPI 的改善。
4. **品牌平台追热点**：IP 换来换去，算法和受众都在重新认识你。
5. **三分钟热度**：内容停更在第 6 周、弱关系激活做了两个月——飞轮停在了点火前一刻。
