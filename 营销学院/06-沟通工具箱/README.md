# 课程 06：沟通工具箱——提问、倾听、讲故事、谈判

> **前置课程**：课程 01（信任方程）/ 课程 04（全流程，工具在流程中使用）
> **预计学习时长**：8–10 小时（含大量演练——本课只能"练会"，不能"看会"）
> **课程性质**：技能训练课。五个工具模块（提问/倾听/讲故事/影响力/谈判），每个都配对话示例与改写练习。
> **主线案例**：陈默的单子继续提供素材。

## 课程目标

学完本课程，你应该能够：

1. 在真实对话中组合使用五类提问工具（漏斗式/标度/魔法问题/后果链/沉默），并知道各自的使用时机与禁忌。
2. 用 3F 过滤器拆解任何一段客户发言，并做出"复述确认 + 命名情绪"式回应。
3. 用 SCQA 把一段干瘪经历改写成 90 秒故事，并维护一个 3–5 篇的个人故事库。
4. 说出影响力六原则各自的正确用法与滥用信号，并在自己的材料里各找到一处应用。
5. 完成一次真实谈判的准备三件套（BATNA 工作表/ZOPA 估算/可交换变量清单），全程不做无条件让步。

## 第 1 课 提问技术：五件武器的组合拳

### 讲解

深谈的质量由问题质量决定。五件武器，各有时机：

| 武器 | 一句话 | 最佳时机 | 禁忌 |
|---|---|---|---|
| 漏斗式组合 | 从宽到窄逐层聚焦 | 深谈开场 | 跳档太快（宽问题没问两下就钻细节） |
| 标度问题 | "1–10 分打几分？" | 痛点模糊、客户含糊时 | 对情绪激动者使用（显得冷漠） |
| 魔法问题 | "这问题消失值多少钱？" | 客户已承认痛、未量化时 | 痛没挖透就问（得到敷衍数字） |
| 后果链 | "然后呢/影响到谁/最坏一次？" | 显性痛 → 隐性痛的展开 | 机械连环问（像审讯） |
| 沉默 | 问完关键问题闭嘴 | 每个重要问题之后 | 用"要不我来说说方案"填补沉默 |

**漏斗式的标准四层**：

```
第 1 层（宽）："你们这块现在整体是怎么运转的？"        → 摸全貌
第 2 层（窄）："里面哪一步最花时间？"                  → 定位痛
第 3 层（深）："上个月这一步实际花了多久？"            → 拿数字
第 4 层（宽）："如果不解决，接下来一个季度会怎样？"     → 放大影响（回到宽，但意义变了）
```

**标度问题的追问术**：不管客户打几分，一律问"**差的那 3 分是什么？**"——客户会自动列出问题清单，这是他用他自己的话说出的需求。

### 对话示例（组合拳）

> **客户**：我们报表这块吧，怎么说呢，还行但也不太行。
> **陈默**：如果 1–10 分给现在的报表流程打个分，你打几分？〔标度〕
> **客户**：6 分吧。
> **陈默**：那差的 4 分是什么？〔标度追问〕
> **客户**：主要是月底太赶，还有口径老对不上……其实上个月还出过一次错。
> **陈默**：那次错，后来怎么收场的？〔后果链：最坏一次〕
> **客户**：（沉默 5 秒）……换汇计划推迟，多花了快两万。
> **陈默**：（不填补沉默，等他继续）〔沉默〕
> **客户**：说实话，那次之后老板现在每个月都要亲自过一遍数，我压力挺大的。

四件武器九轮对话，拿到了：分数、问题清单、故事、数字、深层情绪。**没有任何一句推销**。

### 常见错误与纠正

- 错误 ①：连续问五个标度问题——组合拳变套路，客户疲劳。纠正：每件武器一击即换。
- 错误 ②：问完重要问题客户一沉默就自救式补充——沉默是客户在思考，你一说话就把答案打断了。
- 错误 ③：把魔法问题提前（痛没挖透就问"值多少钱"）——得到的数字会小得无法支撑报价。

### 练习

1. 找人演练 15 分钟深谈，规则：只能问，不能陈述超过一句话；目标用上全部五件武器。
2. 录音回听，标出每一问属于哪件武器、哪一次你破坏了沉默。
3. 把"差的 4 分是什么"用在一次真实对话里，记录客户说出的清单。

### 自测

1. 漏斗式为什么最后要"回到宽"？那一问和第一层的宽问题差在哪？
2. 标度问题对什么状态的客户禁用？替代方案是什么？
3. 沉默为什么有效？它给了客户什么？

## 第 2 课 倾听：3F 过滤器与听说比训练

### 讲解

听不是等对方说完。每段发言用 **3F 过滤器**实时拆三层：

- **Fact 事实**：他说了什么事？（"上个月报表迟了三天"）
- **Feeling 情绪**：他带着什么感受？（自责/委屈/焦虑/无奈）
- **Focus 关注**：他真正在意但没直说的？（老板的信任/自己的位置）

**回应公式：先命名情绪，再复述事实，最后确认关注点。**

> ❌ 只有事实："迟三天，那你们流程哪里卡住了？"（高效但冷，客户感觉在被审问）
> ✅ 3F 式："迟了三天还得让老板来兜底，听起来那阵子你压力不小（情绪）。咱们捋捋当时那三天卡在哪（事实）——你自己最担心的是时效还是准确性（关注）？"

差别不在信息量，在**客户感到被看见**——这是信任方程里"亲密度"变量的主要来源。

**听说比 ≤ 40:60 的训练法**（配合 [课程 08](../08-度量与复盘/README.md) 的度量）：

```
录音回听评分表（每场深谈后）：
□ 我说的字数占比（目标 ≤40%）
□ 我打断次数（目标 0；客户停顿 ≠ 说完）
□ 我复述确认次数（目标 ≥3 次/小时）
□ 我命名情绪次数（目标 ≥2 次/小时）
□ 我在客户说完 2 秒内接话的次数（越少越好——急着接话=在想自己的回应）
```

### 案例

陈默对 CFO 的一次关键倾听：CFO 说了句"我们以前也被乙方坑过"。低手会立刻辩解"我们不一样"。陈默的 3F 回应："被坑过才这么谨慎（情绪）——方便说说上次卡在哪个环节吗（事实）？这次采购里您最想避免重演的是什么（关注）？"CFO 讲了 20 分钟上家供应商的烂尾史——**这段话让陈默的提案里多了一整页"风险与保障"，直接成为后来成交的胜负手**。

### 常见错误与纠正

- 错误 ①：假装倾听（心里排练自己的方案）——破绽在你回应的第一句就暴露（接不上他的情绪）。
- 错误 ②：把命名情绪演成心理医生（"你一定很难过吧"）——克制、具体、基于他说过的原话。
- 错误 ③：只听事实层——信息全收到，信任零积累。

### 练习

1. 3F 拆解练习：找 5 段访谈/播客里客户型的发言，逐段写出三层。
2. 改写练习：把下面这句回应改成 3F 式——客户："这个报价比我预期高不少。"（参考：先接住"高不少"背后的担忧，再问预期与比较对象，最后确认他在意的到底是预算还是回报）
3. 下一场真实对话，录音并跑一遍评分表。

### 自测

1. 为什么"急着接话"是没在听的信号？
2. 亲密度变量与 3F 的关系是什么？
3. 命名情绪的两条红线（心理医生化/猜错硬贴）怎么避开？

## 第 3 课 讲故事：SCQA 结构与三类必备故事

### 讲解

人记不住清单，记得住故事。**SCQA 是把经历压成 90 秒故事的标准结构**：

```
S Situation 背景：一句话交代场景（听众需要的最少背景）
C Complication 冲突：出了什么问题/变化（故事的引擎）
Q Question 关键问题：当时必须回答什么（把听众拉进推理）
A Answer 行动与结果：我做了什么 + 数字结果（高潮）
→ 启示：这段经历和"你"的关系（销售场景的定制尾钩）
```

**三类必备故事**（每个售卖者都该有的故事库）：

| 类型 | 作用 | 使用场合 |
|---|---|---|
| 救火故事 | 展示压力下的专业与担当 | "你们最急的时候靠得住吗？" |
| 从零到一故事 | 展示方法论与搭建能力 | "这事没人做过，你会怎么做？" |
| 失败复盘故事 | 展示诚实与成长性（真实性） | 建立深信任；面试必杀 |

**为什么失败故事效果好**：满屏成功案例的市场里，一个敢讲自己怎么搞砸、怎么复盘的人，可信度反而最高——它同时命中了信任方程的自我导向（降低）与亲密度（升高）。

### 范文（陈默的失败复盘故事，92 秒口述量）

> **S**：前年我给一家贸易公司做过库存预测模型，信心很足。
> **C**：上线第一个月，预测偏差比他们原来的土办法还大——因为我直接拿历史销量建模，没问一句"去年哪些月份是人工压货冲出来的"。
> **Q**：数据看起来都对，为什么结果错了？——**脏数据在进入模型之前就污染了规律本身。**
> **A**：我复盘后重做：先花两周做"业务事件标注"，把促销、压货、断货全部标进数据，再建模，偏差降了六成。从此我的流程里多了一条铁律：**任何数据项目，前 20% 的时间用来理解业务，不是碰数据。**
> **启示**：所以如果咱们合作，第一周我不会急着动手写东西——我要先弄清你们的账是怎么长成今天这样的。

注意"启示"句：把故事的经验**对接到眼前客户的利益**——故事到此才变成销售资产。

### 干瘪经历的改写对照

> ❌ 原版："我负责过财务系统迁移，按期上线，运行稳定。"
> ✅ SCQA："系统迁移最怕切换那晚对不上账（S 藏在共识里）。老系统八年没人敢动，历史数据有三套口径（C）。我们当时要回答：一次性切换还是双轨并行（Q）？我做了三套数据的映射表、演练了两轮，切换当晚差异清零，第二个月结账提前四天（A）。这段经历让我对'口径'两个字有敬畏——也是我今天看你们对账问题的第一直觉（启示）。"

### 练习

1. 用 SCQA 写出你的三类故事各一篇（每篇 ≤150 字），口述录到 90 秒内。
2. 互练：讲给一个人听，复述他记住了什么——他记住的才是你的故事，没记住的是你的稿子。
3. 建立"故事取用表"：高频问题/场合 × 对应故事（面试"讲个失败"、客户"你们靠谱吗"、社交"你是做什么的"）。

### 自测

1. Q（关键问题）这一段为什么不能省？它对听众做了什么？
2. 失败故事在什么时机讲是自杀行为？
3. "启示"句和 FABG 里的 B（收益）是什么关系？

## 第 4 课 影响力六原则：正当使用与滥用警报

### 讲解

Cialdini《Influence》的六原则是说服心理的地基。**销售里的分界线只有一条：原则必须建立在真实上**——真实的好处给出去（互惠）、真实的案例亮出来（社会认同）、真实的期限摆上桌（稀缺）。造假不是"用力过猛"，是自毁信任资产。

| 原则 | 机制 | 销售中的正当用法 | 滥用信号（出现即止损） |
|---|---|---|---|
| 互惠 | 先收到的人想回报 | 触达先给洞察/资料；深谈先给诊断价值 | 给垃圾资料换"人情债"心态 |
| 承诺一致 | 人希望言行一致 | 让客户亲口说出标准与需求（SPIN 的 N 问题） | 逼小承诺套大承诺（低价钓鱼） |
| 社会认同 | 不确定时看同类 | 展示**同行业同规模**客户案例 | 案例注水、盗用 logo |
| 喜好 | 对喜欢的人说 yes | 真诚好奇客户这个人（3F 倾听） | 假装有共同爱好 |
| 权威 | 专家降低决策焦虑 | 公开方法论/数据/作品（课程 02 证据资产） | 头衔堆砌、伪专家姿态 |
| 稀缺 | 有限的机会更被珍惜 | 真实排期/预算周期/名额 | 假截止日（客户一验证即崩塌） |

**组合应用示例（陈默的一封跟进邮件）**：附一份为对方公司定制的对账口径体检小报告（互惠），引用同规模跨境电商的案例与数字（社会认同），给出一页方法论说明（权威），注明"这个季度我还剩一个实施档期"（稀缺——真实）。四个原则，零句自夸。

### 练习

1. 检查你现有的简历/主页/提案/邮件，六原则各找一处可加强的点。
2. 写出你的"滥用红线清单"：哪三条你最容易在不耐烦时破戒？
3. 给下次触达设计一个"真实互惠物"（对方 30 秒内能用上的东西）。

### 自测

1. 为什么说六原则的"技术"部分都很简单，难点全在真实性？
2. 社会认同的案例为什么必须"同行业同规模"？错配的案例有什么反效果？
3. 承诺一致原则与 SPIN 的 N 问题如何互相成就？

## 第 5 课 谈判：从 BATNA 到"绝不分差价"

### 讲解

谈判不是辩论：辩论争对错，谈判**交换利益**。四件核心工具 + 一组技术：

**① BATNA（最佳替代方案）**——谈判力的真正来源：

```
BATNA 工作表（谈判前必填）：
我的 BATNA：这单不成，我的最好出路是？（另一个客户？下季度再谈？）
对方的 BATNA：他不跟我签，他的出路是？（招人？换供应商？忍着？）
对比结论：谁的 BATNA 更痛，谁更需要这单 → 我的底气系数
```

**② ZOPA（可能成交区间）**：`[max(我的底线, 对方底线), min(我的开价上限, 对方的上限)]` 的交集。谈前只能估，谈中用试探校准（"如果范围在 X 到 Y 之间，我们有没有得谈？"）。

**③ 锚定**：先出数的一方设定整场谈判的参照系。**开价要"合理偏高"**：可辩护（有依据）+ 留让步空间。谈薪场景的正确用法：报"期望区间"而非"当前薪资"。

**④ 让步三纪律**：
1. **让步必交换**：降 5000 可以，换预付 50% / 周期延长 / 案例授权 / 两个转介绍。
2. **让步幅度递减**：5000 → 2000 → 500（传递"接近底线"的信号）；等幅或递增的让步在教对方继续压。
3. **绝不全额分裂差价**："那取中间吧"是最懒的收场。替代话术见下。

**Voss 式技术三件**（Chris Voss《Never Split the Difference》）：
- **标注情绪**："听起来这个数字让你们很为难。"（先接情绪再谈数字）
- **校准式提问**：不说"这不合理"，问"**我怎么才能让这个价格对您可行？**"——让对方替你解决你的问题。
- **"不"的力量**：很多时候该争取的回答是"不"而不是"是"——"现在放弃这个方案，对你们来说可以吗？"（人们守卫"不"，防御感最低时真话最多。）

### 完整谈判对话示例（谈薪，逐段标注）

> **HR**：你的期望薪资是 28K，我们最多给到 24K，差距不小。
> **陈默**：24K 和我的预期确实有距离，我理解你们有薪酬带宽的约束。〔标注情绪 + 认可对方处境〕先确认一下：24K 是这个职级的带宽上限，还是本轮的报价？〔摸 ZOPA 边界〕
> **HR**：带宽上限是 26K，特批需要理由。
> **陈默**：明白。这样问吧——**如果要在 26K 谈，我需要让什么变得可行？**〔校准式提问〕
> **HR**：……如果有同级别的硬依据，比如带过数据项目的量化结果。
> **陈默**：可以，我有两个项目的前后数字，今天发你。另外如果 base 到位 26K，**签字费和年度目标奖我可以配合你们的结构调整**——我更在意总包和成长位。〔锚定区间 + 让步交换：拿非现金维度换 base〕
> **HR**：总包思路可以聊，我下周给你方案。

结果：base 从 24 → 26（带宽上限），代价是陈默在签字费上留了让步空间——**没有任何一次无条件让步**。

### 常见错误与纠正

- 错误 ①：不填 BATNA 就上桌——所有底气都是装的，一压就垮。
- 错误 ②：把"分裂差价"当礼貌——它教会对方：报价=漫天要价。
- 错误 ③：只在一个维度上拉锯（价格）——总包维度清单：base/奖金/期权/远程/假期/成长资源/项目选择权/合同周期/付款节奏/案例授权，**维度越多，双赢空间越大**。

### 练习

1. 为你最近一次将要发生的谈判（报价/谈薪/续约）填 BATNA 工作表 + ZOPA 估算 + 可交换变量清单（≥6 项）。
2. 把上一次你"直接让步"的场景重写：让步换回了什么？
3. 演练：与朋友对练"绝不分差价"——目标是三轮拉锯内达成"交换式"收场。

### 自测

1. 为什么说 BATNA 决定谈判力，话术只决定发挥？
2. 让步幅度递减传递了什么信号？等幅让步传递了什么？
3. 校准式提问为什么比反驳有效？它把问题推给了谁？

## 过关标准

- [ ] 完成一场"五件武器"深谈演练（录音，回听标注武器与沉默守卫）。
- [ ] 一场真实对话跑完 3F 评分表：听说比 ≤45:55、零打断、复述 ≥3 次。
- [ ] 三类故事各一篇入库，每篇 ≤90 秒且带"启示"尾钩，至少讲给一个人听过。
- [ ] 六原则自查完成，材料里至少三处得到加强，滥用红线清单成文。
- [ ] 一次真实谈判带三件套上阵，全程零无条件让步（结果输赢不限，过程达标）。

## 常见错误

1. **把工具当表演**：3F 命名情绪像念台词、故事讲得像朗诵——工具的内化标准是"忘了自己在用工具"。
2. **只练喜欢的模块**：技术型的人狂练提问、回避讲故事和情绪命名——而后者恰是信任的来源。
3. **没有录音就没有训练**：听说比和打断次数靠感觉永远不准。
4. **谈判前不做作业**：BATNA 工作表 10 分钟能填完，跳过它输掉的是整场的底气。
