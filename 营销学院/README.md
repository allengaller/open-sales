# 营销学院 · Sales Academy

> **使命**：把"卖自己"从玄学变成工程——用一套可执行、可度量、可迭代的体系，让你的技能与组合优势卖出应有价格。
> **学院哲学**：把自己当产品经营，把销售当系统运行。
> **体例**：每门课程 = 课程目标 → 分课（讲解/案例/练习/自测）→ 过关标准 → 常见错误 → 延伸阅读。**只读不练等于没学。**
> **总索引**：全学院统一主线人物"陈默"（财务业务理解 × Python 自动化的独立顾问），一个单子贯穿九门课。

## 三条学习路径

### 路径 A：完整体系（推荐，也是默认）

```
01 底层认知 → 02 产品化自己 → 03 市场与客户 → 04 销售全流程
→ 05 经典方法论 → 06 沟通工具箱 → 07 个人售卖实战
→ 08 度量与复盘 → 09 九十天训练营（毕业）
```

适合从零重学销售、要建立完整体系的人。全程约 3–4 周学完前八门，再进入 90 天训练营。

### 路径 B：求职速成（2 周冲刺）

```
02 产品化自己（PVP + 电梯陈述）
→ 03 市场与客户（第 5 课决策链：HR/用人经理映射）
→ 04 销售全流程（第 2 课触达 + 第 3 课深谈）
→ 07 个人售卖实战（第 1 课求职：简历 + 面试矩阵 + 谈薪）
```

适合正在找工作的人。拿到 offer 后回头补 01/05/06/08，防止"会打一仗但不会打十仗"。

### 路径 C：自由职业者/接单者（3 周起航）

```
02 产品化自己（组合优势 + 证据资产）
→ 03 市场与客户（ICP + 名单全课）
→ 04 销售全流程（全课，重中之重）
→ 07 个人售卖实战（第 2 课定价与提案 + 第 4 课内容飞轮）
→ 08 度量与复盘（个人 CRM 立刻建起来）
```

适合要靠自己的手艺吃饭的人。首单成交后进入 09 训练营的系统化运营。

## 学习纪律

1. **每课产出物不过夜**：每课的"练习"是课程的一部分，不是选做——过关标准是 checklist，不是阅读进度条。
2. **录音是唯一的诚实的老师**：听说比、打断次数、沉默守卫，感觉永远不准，录音回听才准（课程 06 评分表）。
3. **真实市场是唯一的考场**：前八门的练习可以对人演练，09 训练营的任务必须在真实名单、真实触达、真实深谈上完成。
4. **每周复盘一次**：用 [课程 08](08-度量与复盘/README.md) 的周复盘表——没有度量的销售是碰运气，有度量的销售是可调试的系统。

---

## 学院毕业标准

从 09 训练营毕业时，你应当握有：

- [ ] 一条**真实的漏斗数据**（触达 → 深谈 → 方案 → 成交，各环节数字）
- [ ] 一套**个人话术库**（触达模板 + 深谈问题卡 + 异议库 ≥12 条 + 故事库 ×3）
- [ ] 至少**一个成交或 offer**（任何金额——毕业证不看金额，看闭环）
- [ ] 一份**可持续运转的周复盘节奏**（连续 ≥4 周）
